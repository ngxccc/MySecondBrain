code refactoring /kəʊd ˌriːˈfæktərɪŋ/ (Noun Chunk)

---

**Nghĩa**: Tối ưu hóa / Cải tiến mã nguồn (Viết lại code sạch hơn mà không thay đổi hành vi đầu ra).

**Loại từ**: Noun Phrase (Cụm danh từ).

**Ví dụ**:

- **Code refactoring** improves readability and removes performance bottlenecks.
  _(Tối ưu hóa mã nguồn giúp cải thiện độ dễ đọc và loại bỏ nút thắt hiệu năng)._

**Cách dùng**: Kỹ thuật dọn dẹp syntax, tối ưu hàm và cấu trúc lớp trong phát triển phần mềm.
