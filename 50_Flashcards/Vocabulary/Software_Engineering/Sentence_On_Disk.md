Nghĩa và cách dùng cụm từ **on disk** trong tiếng Anh công nghệ? Nêu loại từ, ví dụ và bản dịch.

---

- **Loại từ (Type)**: Prepositional Phrase / Adverb (Cụm giới từ)
- **Nghĩa (Meaning)**: Đã được lưu trên đĩa cứng / Tập tin thực tế trong ổ đĩa
- **Ví dụ (Example)**:
  - _You can verify that the file content was modified **on disk** using git diff._ (Bạn có thể xác minh nội dung file đã được chỉnh sửa trên đĩa bằng git diff.)
