What is the definition, type, pronunciation, and usage of the term **value type**?

---

- **Type**: Noun Phrase
- **Meaning**: A data type whose value is copied entirely when assigned to a variable or passed into a function.
- **Example**:
  - _In Go, arrays are **value types**, meaning passing an array copies all its elements into the new function frame._
