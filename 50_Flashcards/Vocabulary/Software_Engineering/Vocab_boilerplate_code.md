boilerplate code /ˈbɔɪlərpleɪt kəʊd/ (Noun Chunk)

---

**Nghĩa**: Code rập khuôn (Mã nguồn lặp đi lặp lại mang tính cấu hình ban đầu).

**Loại từ**: Noun Phrase (Cụm danh từ).

**Ví dụ**:

- AI generates repetitive **boilerplate code** in seconds.
  _(AI tạo ra đoạn mã rập khuôn lặp đi lặp lại trong vài giây)._

**Cách dùng**: Dùng để mô tả các đoạn mã khởi tạo thư viện, setup server hoặc cấu hình khung dự án.
