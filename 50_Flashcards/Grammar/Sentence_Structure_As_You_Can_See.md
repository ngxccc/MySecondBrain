Cấu trúc dẫn dắt trực quan: "Như các bạn có thể thấy..." (As you can see on/in...). Nêu công thức và ví dụ.

---

**Cấu trúc:**
`As you can see + on/in + Noun, Subject + Verb`

**Ý nghĩa & Cách dùng:**

- Dùng trong thuyết trình để hướng sự chú ý của khán giả vào một vị trí trực quan cụ thể (màn hình, slide, biểu đồ, tài liệu).

**Ví dụ thực tế:**

- **As you can see on the title slide**, under Section 00, our topic is AI.
  _(Như các bạn có thể thấy trên slide tiêu đề, dưới Phần 00, chủ đề của chúng ta là AI)._
- **As you can see in the diagram**, the client makes an HTTP request to the API gateway.
  _(Như bạn thấy trong sơ đồ, client gửi một HTTP request đến API gateway)._
