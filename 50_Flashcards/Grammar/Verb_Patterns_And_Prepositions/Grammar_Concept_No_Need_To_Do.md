What are the structures for expressing lack of necessity (**There is no need to** vs **don't need to**)?

---

- **Formula / Pattern**:
  - `Pattern 1`: `There is no need to + V-bare`
  - `Pattern 2`: `Subject + don't/doesn't need to + V-bare`
- **Core Explanation**:
  - Cả hai cấu trúc đều dùng để diễn đạt sự không cần thiết. `There is no need to` dùng khách quan, `don't need to` đi với chủ ngữ trực tiếp.
- **Usage & Anchor Cues**:
  - ❌ `no need update to file`
  - ✅ `There is no need to update the file` OR `You don't need to update the file`
- **Concrete Examples**:
  - _`There is no need to create a new helper class.`_ (Không cần thiết phải tạo một class helper mới.)
  - _`You don't need to manually purge the cache.`_ (Bạn không cần phải tự tay xoá cache.)
