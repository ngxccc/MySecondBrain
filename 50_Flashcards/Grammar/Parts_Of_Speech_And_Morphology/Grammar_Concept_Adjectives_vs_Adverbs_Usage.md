# Grammar Concept: Adjectives vs. Adverbs Placement

## TL;DR

Adjectives describe nouns (things, people, services), while adverbs describe verbs (how an action is performed), adjectives (intensity), or other adverbs.

## Core Concept & Formula Rules

1. **Adjective (Tính từ)**:
   - **Target**: Modifies Nouns.
   - **Position**: Before Nouns (`Adjective + Noun`) OR After Linking Verbs (`Subject + be/feel/become + Adjective`).
   - _Example_: `The laggy service degraded user experience.` / `The service was laggy.`

2. **Adverb (Trạng từ)**:
   - **Target**: Modifies Verbs, Adjectives, or Adverbs.
   - **Position**: After/Before Verbs (`Verb + Adverb` / `Adverb + Verb`) OR Before Adjectives (`Adverb + Adjective`).
   - _Example_: `The Go garbage collector ran sluggishly.` / `Latency spiked suddenly.`

## Comparison Matrix

| Target to Modify     | Class to Use  | Pattern    | Example                               |
| :------------------- | :------------ | :--------- | :------------------------------------ |
| Noun (Object/System) | **Adjective** | Adj + Noun | _a **sluggish** service_              |
| Noun (Subject)       | **Adjective** | Be + Adj   | _The service was **laggy**._          |
| Action (Verb)        | **Adverb**    | Verb + Adv | _The application ran **sluggishly**._ |
| Degree of Quality    | **Adverb**    | Adv + Adj  | _an **extremely** laggy system_       |
