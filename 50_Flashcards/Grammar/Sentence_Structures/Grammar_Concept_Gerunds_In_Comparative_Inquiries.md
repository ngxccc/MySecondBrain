How do you correctly formulate **Comparative Questions with Gerunds ($V\text{-ing}$)** when asking for opinions (such as **"Do you find reading data from X more complex than Y?"**)?

---

- **Formula / Pattern**:
  ```text
                     ⎧ Do you think / find + [Gerund Phrase: V-ing] + more [Adjective] than [Noun / V-ing]?
                     ⎪ (e.g., Do you find reading data from SQLite more complex than JSONL?)
  Comparative        -> ⎨
  Question Structure ⎪ Is [Gerund Phrase: V-ing] + more [Adjective] than [Noun / V-ing]?
                     ⎩ (e.g., Is reading and writing data with SQLite more difficult than using JSONL?)
  ```
- **Core Explanation**:
  - Khi hỏi về độ phức tạp/khó khăn của một hành động, sử dụng **Danh động từ (Gerund - $V\text{-ing}$)** làm chủ ngữ hoặc tân ngữ của mệnh đề.
  - Cấu trúc song hành (Parallelism Invariant): Vế so sánh sau `than` phải tương thích về mặt từ loại với vế trước (nếu trước dùng `reading from X` thì sau dùng `using Y` hoặc `from Y`).
- **Usage & Anchor Cues**:
  - ❌ `You see read data from sqlite is more complex than jsonl?`
  - ✅ `Do you find reading and writing data from SQLite more complex than using JSONL?`
  - ❌ `Is write file hard than sqlite?`
  - ✅ `Is writing to files harder than querying SQLite?`
- **Concrete Examples**:
  - _`Do you think managing SQLite migrations introduces more cognitive overhead than editing JSONL?`_ (Bạn có nghĩ việc quản lý migration SQLite tạo ra nhiều tải nhận thức thừa hơn so với chỉnh sửa JSONL không?)
  - _`Is parsing atomic files faster than deserializing a monolithic payload?`_ (Việc phân tích cú pháp các file nguyên tử có nhanh hơn giải tuần tự hóa payload nguyên khối không?)
