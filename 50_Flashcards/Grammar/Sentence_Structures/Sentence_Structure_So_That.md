What is the cause-and-effect pattern for **So + Adjective + that + Clause**?

---

- **Formula / Pattern**:
  - `Subject + be/V + so + Adj/Adv + that + Subject + Verb`
- **Core Explanation**:
  - Diễn tả sự vật/hiện tượng có tính chất đến mức độ cao gây ra kết quả ở mệnh đề sau `that`.
- **Usage & Anchor Cues**:
  - `so + Adj + that` (chỉ mức độ gây ra kết quả). Phân biệt với `so that + Clause` (chỉ mục đích).
- **Concrete Examples**:
  - _`The execution time was so long that the API timed out.`_ (Thời gian thực thi quá lâu đến nỗi API bị timed out.)
  - _`He coded so fast that he finished the feature before lunch.`_ (Anh ấy viết code nhanh đến nỗi hoàn thành tính năng trước giờ ăn trưa.)
