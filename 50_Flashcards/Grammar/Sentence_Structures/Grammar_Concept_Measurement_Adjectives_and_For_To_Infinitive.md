How do you correctly express **Measurements with Adjectives (e.g., 500 lines long, 2 meters high)** and use the **"It is [Adj] for [Object] to-V"** pattern?

---

- **Formula / Pattern**:
  ```text
                      ⎧ Subject + is/are + [Quantity/Unit] + [Adjective] (long/high/wide/old)
                      ⎪ (e.g., The file is over 500 lines long. The server is 3 years old.)
  Patterns & Formats  -> ⎨
                      ⎪ It is + [Adjective] + for [Object] + to-V (Infinitive)
                      ⎩ (e.g., It is hard for an agent to edit this file.)
  ```
- **Core Explanation**:
  - **Measurement + Adjective**: Đơn vị đo lường đứng trước tính từ mô tả kích thước (`500 lines long`, `100 megabytes big`, `10 meters wide`), KHÔNG dùng trật tự ngược như tiếng Việt hoặc ký hiệu toán học chen ngang (❌ `it long 500 > line` $\rightarrow$ ✅ `it is over 500 lines long`).
  - **Cấu trúc `It is [Adj] for [Object] to-V`**: Sau `for [Object]`, hành động bắt buộc phải ở dạng **Động từ nguyên mẫu có to (to-Infinitive)** (❌ `hard for agent edit` $\rightarrow$ ✅ `hard for an agent to edit`).
- **Usage & Anchor Cues**:
  - ❌ `The file is long 500 line, hard for agent edit`
  - ✅ `The file is over 500 lines long, making it hard for an agent to edit`
  - ❌ `This query is fast 2 seconds`
  - ✅ `This query is 2 seconds faster`
- **Concrete Examples**:
  - _`The monolithic configuration file is 800 lines long, which slows down parsing.`_ (File cấu hình nguyên khối dài 800 dòng, làm chậm quá trình phân tích cú pháp.)
  - _`It is crucial for developers to write idempotent API endpoints.`_ (Việc các lập trình viên viết endpoint API có tính lũy thỏa là cực kỳ quan trọng.)
