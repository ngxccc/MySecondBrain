What are the natural technical collocations for UI consistency (**fit the UI** / **match the design**)?

---

- **Formula / Pattern**:
  - `fit + the current / existing UI`
  - `match + the existing UI design`
  - `blend seamlessly + with the UI`
- **Core Explanation**:
  - Khi miêu tả việc thiết kế thành phần mới sao cho hài hòa với giao diện đã có, dùng động từ `fit`, `match` hoặc `blend seamlessly`.
- **Usage & Anchor Cues**:
  - `fit` và `match` đi trực tiếp với tân ngữ `the UI` mà không cần giới từ `with`.
- **Concrete Examples**:
  - _`Please ensure the new component fits the current UI.`_ (Vui lòng đảm bảo thành phần mới vừa vặn/hài hòa với UI hiện tại.)
  - _`The dark theme matches the existing design system.`_ (Theme tối khớp với design system hiện tại.)
