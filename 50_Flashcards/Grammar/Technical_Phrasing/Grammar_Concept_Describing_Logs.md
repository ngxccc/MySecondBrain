What are the introductory sentence patterns for presenting error logs or stack traces (**I got an error when...** / **Here is the stack trace...**)?

---

- **Formula / Pattern**:
  - `Pattern 1`: `I got an error when I ran [Command / App]: [Log]`
  - `Pattern 2`: `The application crashed with the following stack trace: [Log]`
  - `Pattern 3`: `Here is the exception log I encountered: [Log]`
- **Core Explanation**:
  - Mẫu câu chuyên nghiệp dùng khi chia sẻ log lỗi hoặc stack trace cho đồng nghiệp hoặc AI hỗ trợ.
- **Usage & Anchor Cues**:
  - Tránh dán log trần trụi mà không có câu dẫn nhập ngữ cảnh.
- **Concrete Examples**:
  - _`I got an error when I ran the migration script: [Log]`_ (Tôi gặp lỗi khi chạy script migration: [Log])
  - _`The server crashed with the following stack trace: [Log]`_ (Server bị crash với stack trace sau đây: [Log])
