What are the natural technical collocations for expressing system errors (**throw an error** / **get an error**)?

---

- **Formula / Pattern**:
  - `Subject + throw / produce / return + an error`
  - `Subject + get / encounter + an error`
- **Core Explanation**:
  - Trong tiếng Anh lập trình, không nói "code bị error" (`my code was error`). Phải dùng động từ chuyên ngành: `throw/produce/encounter an error`.
- **Usage & Anchor Cues**:
  - ❌ `my component was error`
  - ✅ `my component threw an error` OR `I got an error in my component`
- **Concrete Examples**:
  - _`The function threw a runtime error when passed null.`_ (Hàm bắn ra lỗi runtime khi bị truyền null.)
  - _`I encountered a build error after updating dependencies.`_ (Tôi gặp lỗi build sau khi cập nhật phụ thuộc.)
