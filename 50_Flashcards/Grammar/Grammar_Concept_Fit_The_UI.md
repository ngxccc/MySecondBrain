Cách dùng cụm từ **fit the current UI / match the current design** trong tiếng Anh kỹ thuật?

---

- **Quy tắc**: Khi muốn giao diện mới hài hòa với thiết kế có sẵn, dùng cụm **`fit the UI`**, **`match the design`**, hoặc **`blend seamlessly with the current UI`**.
- ❌ _feed phù hợp với ui hiện tại_ $\rightarrow$ ✅ **make it fit the current UI** hoặc **match the existing UI design**
- **Ví dụ**: _Please ensure the new component **matches the existing UI**._ (Vui lòng đảm bảo thành phần mới phù hợp với giao diện hiện tại.)
